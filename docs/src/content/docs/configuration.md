---
title: Configuration
description: Configure the Nebari Starlight theme.
---

The `nebari()` plugin accepts a small set of options:

```js
starlight({
  title: 'My Pack',
  plugins: [nebari({ logoHref: 'https://nebari.dev/' })],
});
```

- `logoHref` — where the header logo links to. Defaults to the site's own base.
